= Delete a token for a user in a group

[.api-doc-operation .api-doc-operation-delete]#DELETE# [.api-doc-code-block]#`/accounts/{account_id}/core/v1/groups/{group_id}/users/{user_id}/tokens/{token_id}`#



Removes the specified Token API resource.

*Side Effects*

* The corresponding API token credential is removed from the credential service as a side effect.


== Parameters

[cols=5*,options=header]
|===
|Name
|Type
|In
|Required
|Description

|account_id
|string
|path
|True
a|ID of the containing account resource

* example: {{.Account}}


|group_id
|string
|path
|True
a|ID of the containing group resource


|user_id
|string
|path
|True
a|ID of the containing user resource


|token_id
|string
|path
|True
a|ID of the token collection to list


|===
