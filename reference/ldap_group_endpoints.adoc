= Astra API (ACC) LDAP group endpoints
:imagesdir: ../media/

[.lead]
View the groups on the configured Lightweight Directory Access Protocol (LDAP) server. These endpoints are read-only.

The LDAP Group API provides read-only access to LDAP groups within the configured LDAP server.
