= Astra API (ACC) ASUP endpoints
:imagesdir: ../media/

[.lead]
Create AutoSupport (ASUP) bundles and optionally upload them to NetApp to help with troubleshooting.

The ASUP API provides access to ASUP resources in order to create and optionally upload the AutoSupport bundles.
