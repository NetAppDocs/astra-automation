= Astra API (ACC) cloud endpoints
:imagesdir: ../media/

Manage cloud resources so that you can connect to specific clouds and manage your clusters and applications in them.

The Cloud API provides access to cloud resources to allow clients to connect to specific clouds to manage clusters and applications.
