= List all AppMirror resources

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/accounts/{account_id}/k8s/v1/appMirrors`#

Defined values are:

* Minimum length: 0
* Maximum length: 2
