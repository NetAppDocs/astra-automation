= Delete an execution hook override resource

[.api-doc-operation .api-doc-operation-delete]#DELETE# [.api-doc-code-block]#`/accounts/{account_id}/k8s/v1/apps/{app_id}/executionHookOverrides/{executionHookOverride_id}`#



Removes the specified Execution Hook Override API resource.

*Side Effects*

* Any execution hook with a hookType value of "netapp" that applies to the specified application will be enabled when a new execution hook override is deleted if it had an enabled value of "false".



CAUTION: This operation is deprecated.
