= Delete an application backup for an app

[.api-doc-operation .api-doc-operation-delete]#DELETE# [.api-doc-code-block]#`/accounts/{account_id}/k8s/v1/apps/{app_id}/appBackups/{appBackup_id}`#



Removes the specified Application Backup API resource.
Backups in progress will be canceled, and then deleted.

*Side Effects*

* If a backup is complete, the backup data is deleted.


== Parameters

[cols=5*,options=header]
|===
|Name
|Type
|In
|Required
|Description

|account_id
|string
|path
|True
a|ID of the containing account resource

* example: {{.Account}}


|app_id
|string
|path
|True
a|ID of the containing app resource


|appBackup_id
|string
|path
|True
a|ID of the appBackup collection to list


|===
