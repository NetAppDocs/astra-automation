= Retrieve an application asset for an app

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/accounts/{account_id}/k8s/v1/apps/{app_id}/appAssets/{appAsset_id}`#



Returns the stored Application Asset API resource in the JSON response body.


== Parameters

[cols=5*,options=header]
|===
|Name
|Type
|In
|Required
|Description

|account_id
|string
|path
|True
a|ID of the containing account resource

* example: {{.Account}}


|app_id
|string
|path
|True
a|ID of the containing app resource


|appAsset_id
|string
|path
|True
a|ID of the appAsset collection to list


|===

== Response

```
Status: 200, Returns the stored Application Asset API resource in the JSON response body.
```


[cols=4*,options=header]
|===
|Name
|Type
|Required
|Description

|type
|string
|True
a|Media type of the resource.
Defined values are:

* "application/astra-appAsset"


|version
|string
|True
a|Version of the resource.
Defined values are:

* "1.0"
* "1.1"


|id
|string
|True
a|Globally unique identifier of the resource.
Defined values are:

* Conforms to the UUIDv4 Schema


|assetType
|string
|True
a|JSON string containing a value indicating what type of asset is being described as obtained from Kubernetes.
Defined values are:

* Minimum length: 1
* Maximum length: 254


|creationTimestamp
|string
|True
a|JSON string containing a timestamp indicating when the Kubernetes metadata was created.
Defined values are:

* Conforms to the ISO-8601 Date Time Schema


|GVK
|link:#GVK[GVK]
|True
a|JSON object containing a Kubernetes group/version/kind.


|resource
|link:#type_json[type_json]
|False
a|JSON object containing the entire content of the Kubernetes resource definition.


|assetID
|string
|True
a|JSON string containing an identifier assigned by Kubernetes.
Defined values are:

* Conforms to the Astra Identifier Schema


|labels
|array[link:#labels[labels]]
|True
a|JSON array of JSON objects, each containing a Kubernetes labels associated with the asset.
If no details are available, this array will be empty.

* Minimum items: 0


|assetName
|string
|True
a|JSON string containing a name assigned by Kubernetes.
Defined values are:

* Minimum length: 1
* Maximum length: 254


|namespace
|string
|False
a|JSON string containing a namespace assigned by Kubernetes.
Defined values are:

* Minimum length: 1
* Maximum length: 254


|metadata
|link:#type_astra_metadata[type_astra_metadata]
|True
a|Client and service-specified metadata associated with the resource.
Defined values are:

* Conforms to the Astra Metadata Schema


|===
