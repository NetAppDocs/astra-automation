= Astra API (ACC) execution hook override endpoints
:imagesdir: ../media/

[.lead]
Disable the preloaded NetApp execution hooks for a specific application. Check the deprecation information on the page before you use these endpoints.

The Execution Hook Override API allows a user to disable the preloaded "netapp" execution hooks for a specific application. (*NOTE BELOW API DEPRECATIONS*)
