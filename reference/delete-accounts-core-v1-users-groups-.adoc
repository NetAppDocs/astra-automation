= Delete a group for a user

[.api-doc-operation .api-doc-operation-delete]#DELETE# [.api-doc-code-block]#`/accounts/{account_id}/core/v1/users/{user_id}/groups/{group_id}`#



Removes the specified Group API resource.

*Side Effects*

* The following resources associated with the group are deleted:
* Role bindings referring to the group


== Parameters

[cols=5*,options=header]
|===
|Name
|Type
|In
|Required
|Description

|account_id
|string
|path
|True
a|ID of the containing account resource

* example: {{.Account}}


|user_id
|string
|path
|True
a|ID of the containing user resource


|group_id
|string
|path
|True
a|ID of the group collection to list


|===

== Response

```
Status: 204, Indicates if the group resource was deleted.
```
