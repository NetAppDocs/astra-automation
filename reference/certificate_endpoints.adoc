= Astra API (ACC) certificate endpoints
:imagesdir: ../media/

[.lead]
Manage the admin-trusted certificates that Astra Control uses to establish outgoing connections.

The Certificate API represents admin-trusted certificates that are used for establishing outgoing connections.
