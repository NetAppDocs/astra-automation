= Retrieve an LDAP user

[.api-doc-operation .api-doc-operation-get]#GET# [.api-doc-code-block]#`/accounts/{account_id}/core/v1/ldapUsers/{ldapUser_id}`#



Returns a JSON object representing the stored LDAP resource.


== Parameters

[cols=5*,options=header]
|===
|Name
|Type
|In
|Required
|Description

|account_id
|string
|path
|True
a|ID of the containing account resource

* example: {{.Account}}


|ldapUser_id
|string
|path
|True
a|ID of the ldapUser collection to list


|===

== Response

```
Status: 200, Returns a JSON object representing the stored LDAP resource.
```


[cols=4*,options=header]
|===
|Name
|Type
|Required
|Description

|type
|string
|True
a|Media type of the resource.
Defined values are:

* "application/astra-ldapUser"


|version
|string
|True
a|Version of the resource.
Defined values are:

* "1.0"


|id
|string
|True
a|Globally unique identifier of the resource.
Defined values are:

* Conforms to the UUIDv4 Schema


|email
|string
|False
a|JSON string representing the email of the LDAP user.
Defined values are:

* Minimum length: 3
* Maximum length: 63


|firstName
|string
|False
a|JSON string representing the first name of the LDAP user.
Defined values are:

* Minimum length: 1
* Maximum length: 63


|lastName
|string
|False
a|JSON string representing the last name of the LDAP user.
Defined values are:

* Minimum length: 1
* Maximum length: 63


|cn
|string
|False
a|JSON string representing the LDAP group name.
Defined values are:

* Minimum length: 1
* Maximum length: 63


|dn
|string
|False
a|JSON string representing the distinguished name of the LDAP group.
Defined values are:

* Conforms to RFC 4514


|metadata
|link:#type_astra_metadata[type_astra_metadata]
|True
a|Client and service-specified metadata associated with the resource.
Defined values are:

* Conforms to the Astra Metadata Schema


|===
