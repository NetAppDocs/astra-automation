= Astra API (ACC) storage backend endpoints
:imagesdir: ../media/

[.lead]
Manage the storage backends, which are the providers of storage services that your managed clusters and applications can use.

The Storage Backend API provides access to representations of providers of storage services (storage backends) that can be used by managed clusters and applications.
