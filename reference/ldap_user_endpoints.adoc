= Astra API (ACC) LDAP user endpoints
:imagesdir: ../media/

[.lead]
View the users on the configured Lightweight Directory Access Protocol (LDAP) server. These endpoints are read-only.

The LDAP User API provides read-only access to LDAP users within the configured LDAP server.
