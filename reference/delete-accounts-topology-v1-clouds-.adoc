= Delete a cloud

[.api-doc-operation .api-doc-operation-delete]#DELETE# [.api-doc-code-block]#`/accounts/{account_id}/topology/v1/clouds/{cloud_id}`#



Deletes the requested cloud instance and any non-managed clusters and volumes associated with that specific cloud.


== Parameters

[cols=5*,options=header]
|===
|Name
|Type
|In
|Required
|Description

|account_id
|string
|path
|True
a|ID of the containing account resource

* example: {{.Account}}


|cloud_id
|string
|path
|True
a|ID of the cloud collection to list


|===

== Response

```
Status: 204, Indicates if the cloud resource was deleted.
```
